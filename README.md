# 雙Q大冒險日記（手帳拍立得風）

暖色手帳/拍立得風格的互動網站，全新流程：待機封面 → 4 段劇情影片 → 嬰兒車裝備小遊戲（猜性別）→ 5 秒倒數 → 彩帶公布 → 感謝＋拍立得 → 匿名比例結果。

## 檔案說明

- `index.html` / `style.css` / `script.js`　網站主體
- `admin.html` / `admin.js`　後台設定頁（組合名稱、公布答案、拍立得照片、背景音樂、版面位置微調、所有畫面文字）
- `firebase-config.js`　你要填入自己 Firebase 設定的地方（**必填，否則資料無法同步給所有訪客**）
- `assets/`　六支影片＋一首背景音樂的資料夾（見下方說明）

## 這一版的流程說明

1. **待機迎賓**：全螢幕自動循環播放 `assets/cover-standby.mp4`，中央有呼吸燈效果的「翻開第一頁」按鈕。點擊後影片暫停，彈出暱稱輸入對話框。
2. **劇情放映**：輸入暱稱後，先出現一個像素風對話框跟玩家打招呼（文字裡會帶入剛剛輸入的暱稱），點一下才開始依序播放 `assets/story-1.mp4` ~ `story-4.mp4` 四段影片（字幕用影片本身內嵌的文字）。第 4 段播完後畫面會定格在最後一格（爸爸滿頭問號的畫面），疊上「……所以，到底是男生還是女生？」的像素風對話框，再點一下才進入嬰兒車環節。整段期間都可以點右下角「略過所有影片」直接跳到嬰兒車環節（連同這兩個對話框一起跳過）。
3. **嬰兒車裝備**：`assets/stroller-bg.mp4` 滿版當背景（跟封面、劇情影片同樣處理），兩個座位點直接疊在影片裡雙人嬰兒車的座位上，下方半透明面板放配件（🧢 棒球帽／🎀 蝴蝶結）。玩家先點配件、再點左座或右座裝上去；兩邊都裝好後，系統自動判定組合（兩頂帽子＝熱鬧男團、兩個蝴蝶結＝前世情人、一邊一種＝龍鳳組合），彈出確認對話框，可以留一句選填的祝福再送出。
4. **倒數與公布**：送出後 5 秒倒數，接著依照後台設定的正確答案，放出對應顏色的彩帶（全藍／全粉／藍粉交錯）並公布結果。這三個畫面（公布結果／感謝／結果統計）統一改成深色遊戲面板風格、搭配像素風標題字型，背景用待機影片的模糊截圖營造一致的氛圍。
5. **感謝＋拍立得**：打字機效果的感謝詞，加上角落一張可自訂的「未來一家五口」拍立得照片。
6. **匿名結果**：最後可以查看所有人預測的比例分佈（不顯示姓名、只看比例），沒有「再玩一次」按鈕，避免重複計分。

### 嬰兒車座位對齊影片

座位的位置是用百分比疊在 `stroller-bg.mp4` 上，目前預設值是照你上傳的這支影片對齊的，如果之後換了新的嬰兒車影片、座位對不準，到後台「版面位置微調」卡片用百分比重新調整即可（不用改程式碼）。

### 公布／感謝／結果頁的視覺風格

目前是用「待機影片的模糊截圖＋深色遊戲面板＋像素風字型（DotGothic16）」營造跟劇情影片一致的氛圍，還沒有用到你生成的美術圖。如果想要更精緻、更貼合劇情影片畫風的版本，可以幫我生成以下素材（都是直向 9:16，跟你目前給的影片風格一致即可）：

- **公布結果／感謝／結果統計** 共用背景：一張安靜、留白夠多的室內場景（例如客廳一角、嬰兒房），畫面中間偏暗一點，方便疊文字。可以是靜態圖，也可以是像 `stroller-bg.mp4` 那樣的輕微動態影片。
- 如果想讓三個畫面各自有不同情境（公布結果更歡慶、感謝更溫馨、結果統計更像「日記本」），也可以分開做三張／三支，跟我說就好。

沒有的話目前這版本也可以直接使用，之後素材好了隨時可以再加。

### 背景音樂

畫面左上角有一個圓形音符按鈕，玩家從點「翻開第一頁」開始，背景音樂就會持續播放，不會因為切換場景、按任何按鈕而中斷，只有玩家自己點那個按鈕才會靜音／取消靜音。每支影片本身的聲音維持靜音，只有這首背景音樂會出聲。音樂網址可以在後台「拍立得照片」卡片下方的「背景音樂網址」欄位設定，預設抓 `assets/bgm.mp3`。

## 步驟二：建立 Firebase 專案（免費）

1. 前往 https://console.firebase.google.com/ ，新增專案。
2. 「建構」→「Firestore Database」→「建立資料庫」，位置選 `asia-east1`，規則先選「測試模式」。
3. 「專案總覽」→ 網頁圖示新增網頁應用程式，把出現的 `firebaseConfig` 內容貼到 `firebase-config.js`。
4. （建議）到 Firestore →「規則」分頁，設定成：
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if true; // 僅適用於這種一次性小型活動網站
       }
     }
   }
   ```

const ADMIN_PASSCODE = "changeme1005";

## 步驟四：使用後台（admin.html）

首頁右下角有個 ⚙ 連結，或直接開啟 `你的網址/admin.html`：

1. **裝備組合名稱**：修改「熱鬧男團／前世情人／龍鳳組合」的顯示名稱（背後判定邏輯固定，只改名字）。
2. **公布正確答案**：選好答案後按「公布這個答案」，**請等你確定要公布時才按**，一按下去所有訪客立刻看到結果。
3. **拍立得照片／背景音樂**：貼入「未來一家五口」照片的網址（同樣建議先放進 GitHub repo 的 assets 資料夾再貼相對路徑，或用圖床網址），沒設定會顯示預設的插畫佔位圖案；下方還有「背景音樂網址」欄位，預設是 `assets/bgm.mp3`。
4. **版面位置微調**：調整封面按鈕、以及嬰兒車兩個座位在影片上的位置（座位是用百分比座標）。
5. **文字內容編輯**：網站上所有固定文字都能在這裡修改。

建議順序：先把影片、組合名稱、文字都設定好 → 上傳 GitHub 上線 → 等確定要公布的時候，再回後台選答案並公布。

## 步驟五：上傳到 GitHub 並上線（GitHub Pages）

1. 在 GitHub 建立新的 repository。
2. 上傳這個資料夾裡所有檔案（含 `assets/` 整個資料夾）：
   ```
   git init
   git add .
   git commit -m "twin gender reveal diary site"
   git branch -M main
   git remote add origin 你的repo網址
   git push -u origin main
   ```
3. Settings → Pages，Source 選 `main` 分支、`/ (root)`，儲存。
4. 稍等 1-2 分鐘會出現網址（例如 `https://你的帳號.github.io/repo名稱/`），分享給親友。

## 之後想再更新

- 改組合名稱 / 公布答案 / 拍立得照片網址 / 背景音樂網址 / 版面位置 / 所有文字內容（含兩個過場對話框文字）：直接在 `admin.html` 後台操作，不需要重新上傳程式碼。
- 換影片：直接用新檔案覆蓋 `assets/` 資料夾裡對應的檔名，再重新上傳那幾個檔案就好。

## 小提醒

- `firebase-config.js` 的設定值是「前端公開金鑰」，出現在原始碼中是正常的，安全性靠 Firestore 規則把關。
- 分數存在 `stats/comboGuesses` 文件的 `BB` / `GG` / `BG` 三個欄位；每個人的暱稱、組合、祝福存在 `guesses` 集合（不會公開顯示姓名，只用來統計比例）。
- 後台設定分別存在 `config/comboOptions`、`config/uiText`、`config/visualAssets`、`config/layoutPositions`；公布答案存在 `reveal/answer`。
